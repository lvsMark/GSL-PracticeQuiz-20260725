# GSL Practice Quiz

A single-page, self-contained interactive practice quiz for CPA Australia's Global Strategy and Leadership (GSL) subject.

- 409 multiple-choice questions covering Modules 1–7
- Filter by module, choose question count, shuffle, and review-missed-only mode
- Instant feedback with explanation, supporting quote, and source reference for every question
- Progress is stored locally in your browser (no backend, no accounts)

Live site: https://lvsmark.github.io/GSL-PracticeQuiz-20260725/

Combined from five separately compiled mock exam banks (Modules 1–3, 1–4, 4–5, 4–7, and 6–7).
